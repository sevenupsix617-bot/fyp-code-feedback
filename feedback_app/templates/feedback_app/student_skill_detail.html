How this Topic score is calculated: The heuristic question-mark rubric is: solved = 100; exact output match but unresolved = 75; normalized output match but unresolved = 65; output mismatch = 45; classified issue without decisive output evidence = 35; unsuccessful execution = 20; no reliable scoring signal = 0. Multi-Topic marks are attributed using baseline Topic levels, with equal shares when a baseline is zero and a 100-point cap. This Topic score applies an exponential moving average (EMA, α=0.5) to every attributed attempt in time order: recent attempts have more weight, so earlier errors gradually fade. The line above shows the original question marks over time. The table also shows the baseline-weighted Topic credit for each attempt, recalculated from current baselines. This is a prototype heuristic, not a standardised measurement of knowledge.
